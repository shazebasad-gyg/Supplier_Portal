holistic Portal Optimization Engagement metric published in August 2026. Preserved
verbatim, in chronological order. None of these are current: the current definition
is
[Portal Optimization Engagement (v1)](https://getyourguide.atlassian.net/wiki/spaces/DA/pages/4763779185).

Before being collected here these files were untracked scratch in `dap-harness`
(`projects/supplier-portal-engagement/` for the board summaries, `temp/` for
everything else).
